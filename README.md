# 論文フォーマット自動生成ツール
サイトURL : [卒論フォーマット](https://hiranoyudai.pythonanywhere.com/)
## 製作者
平野裕大
## 機能
フォームに必要事項を入力する.

入力されたタイトルや名前、学生番号などを論文執筆に必要な以下のファイルに反映し、それらをzipに圧縮したものをダウンロードできる.

また、ローカルリポジトリも作成されている

- thesis.tex
- thesis.pdf
- llmk.toml
- README.md
- csg-thesis.bst
- csg-thesis.sty
- javassist.eps
- latexmkrc
- thesis.bib
